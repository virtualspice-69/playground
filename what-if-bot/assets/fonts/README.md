# Meme font

Drop a bold sans-serif `.ttf` font here for `/meme` text (e.g. Impact, or a
free alternative like "Anton" or "Bangers" from Google Fonts — both are
free/open-license and look like the classic meme font). Any `.ttf` works;
the bot picks the first one it finds.

If no font is added, memes still work but fall back to a plain default font.
