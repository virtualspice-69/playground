# Meme templates

Drop blank/background images here (jpg/png/webp) that `/meme` will overlay
top/bottom text on when a user doesn't reply to their own photo. Good
templates: your existing $IF Guy renders with empty space near the top and
bottom for text.

After adding files, run `python scripts/build_manifest.py` (or just restart
the bot — it auto-detects new files).
