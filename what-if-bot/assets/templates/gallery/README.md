# Community art gallery

This is where your 250+ finished art/animation pieces go — images (jpg/png/webp)
and animations (gif/mp4/webm/mov). `/random` and `/gif` pull from here.

You can organize into further subfolders (e.g. `gallery/comic/`,
`gallery/anime/`) — the subfolder name becomes a category, which future
commands can filter on.

After adding files, run `python scripts/build_manifest.py` (or just restart
the bot — it auto-detects new files).
