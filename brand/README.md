# Gitbank Brand Standards — Volume I

*The private bank of the commit.*

Open **[gitbank-brand-kit.html](gitbank-brand-kit.html)** in a browser to view the full
brand book. It is a single self-contained file — fonts embedded, no network required.

## The system

| Element | Choice |
|---|---|
| Concept | Swiss private-banking discretion, drawn with the precision of a ledger |
| Crest | A `G` drawn as a vault ring; two nodes mark the commit and the HEAD |
| Ground | Obsidian `#0A0D0F` and Vault Green `#0F2419` |
| Accent | Champagne `#C9A961`, hot-foil gradient `#8F7134 → #F3E3AE` (≤ 10% of any layout) |
| Stock | Ecru `#EFE9DB` for stationery |
| Engraved voice | Marcellus — headings and marks, never bolded |
| Spoken voice | Jost — body and interface |
| Ledger voice | IBM Plex Mono — numbers, hashes, receipts |
